Dolphain Studio Help

Welcome to the Dolphain Studio! This is a browser-based environment for analyzing underwater acoustic data.

Getting Started

  1. Select a File: Choose a recording from the list on the left.
  2. Choose an Example: Use the dropdown menu above the code editor to load different analysis scripts.
  3. Run Code: Click "Run Code" to execute the Python script and see the results.

Available Libraries

The environment includes:

  • dolphain: Our custom library for acoustic analysis.
  • numpy, scipy: For numerical processing.
  • matplotlib: For plotting (pre-configured for dark mode).

Key Dolphain Functions

  • dolphain.EARS(filename): Load an EARS recording.
  • dolphain.signal.wavelet_denoise(data): Clean noisy signals.
  • dolphain.plotting.plot_overview(data): Generate standard plots.

Tip: You can edit the code freely! Try changing parameters or writing your own analysis scripts.
